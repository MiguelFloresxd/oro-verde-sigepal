# Requisitos

## Funcionales
| ID | Requisito |
|---|---|
| RF-01 | Mostrar el catálogo de presentaciones con su precio |
| RF-02 | Permitir armar un carrito y ver el total |
| RF-03 | Calcular el recargo cuando el cliente pide factura |
| RF-04 | Enviar el pedido por WhatsApp con el mensaje prellenado |
| RF-05 | Registrar el pedido en la base de datos |
| RF-06 | Permitir crear cuenta e iniciar sesión (cliente) |
| RF-07 | Mostrar al cliente su historial de compras y repetir un pedido |
| RF-08 | Gestionar pedidos y sus estados desde el panel |
| RF-09 | Registrar pagos y avisar al cliente por WhatsApp |
| RF-10 | Listar clientes con cuenta e invitados |
| RF-11 | Editar precios, productos, stock y stock mínimo |
| RF-12 | Alertar stock bajo y bloquear productos agotados |

## No funcionales
| ID | Requisito |
|---|---|
| RNF-01 | Diseño responsive (celular primero) |
| RNF-02 | Acceso a datos restringido por rol (cliente / administradora) |
| RNF-03 | El precio y el stock se validan en el servidor |
| RNF-04 | Carga del catálogo en menos de 3 segundos |
| RNF-05 | Costo de operación cero (planes gratuitos) |
| RNF-06 | Funciona con respaldo de catálogo si la base de datos no responde |
| RNF-07 | Código mantenible: lógica separada de la interfaz y con pruebas |

> Alinear los códigos y el texto con el documento de requisitos entregado en la presentación.
